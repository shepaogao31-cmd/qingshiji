# 轻食计 · AI 健康饮食助手

一个 AI 驱动的个人健康与饮食管理网页应用。围绕「算得准、吃得明白、练得科学」设计，帮助用户管理体重、记录饮食、追踪运动，并获得 AI 饮食与训练建议。

## 功能

- **身体数据分析**：输入身高体重（可选年龄、性别、腰围、颈围），实时计算 BMI、体脂率（估算值）、基础代谢（BMR）与每日总消耗（TDEE）
- **目标管理**：设置增肌 / 减脂目标与目标体重，展示进度与差值
- **饮食记录**：按早/午/晚/加餐记录，自动汇总热量与蛋白质、碳水、脂肪；内置日常食物（按克）与餐厅食物（按份/个）两类食物库
- **AI 拍照识别**：拍摄食物照片，AI 识别食物种类与份量，确认后计入热量
- **联网搜索**：食物库外的食物可通过 AI 联网搜索补充营养数据，并可一键存入自定义食物库
- **AI 饮食推荐**：根据目标体重、TDEE 与增肌/减脂目标生成全日或单餐推荐，支持一键添加
- **运动记录**：常见运动按 MET 值计算消耗，实时展示热量缺口 / 盈余
- **训练计划**：居家无器械与健身房双场景，按每周运动时长区分新手 / 进阶强度
- **健康安全**：减脂目标热量不低于 BMR 的 80%，全程提示「健康管理参考，不构成医疗建议」

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 框架 | React 19 + TypeScript 5.9 |
| 构建 | Vite 8 |
| 样式 | Tailwind CSS v4 + CVA |
| UI 组件 | shadcn/ui（基于 Radix UI） |
| 路由 | react-router-dom v7 |
| 图表 | echarts / echarts-for-react / recharts |
| 动画 | framer-motion / gsap / @formkit/auto-animate |
| 表单 | react-hook-form + zod |
| 图标 | lucide-react |

## 本地运行

```bash
npm install
npm run dev      # 开发服务器，默认 http://localhost:5173
npm run build    # 生产构建，输出到 dist/
npm run lint     # 类型检查 + ESLint
```

## 目录结构

```
src/
├── index.tsx                # 应用入口
├── app.tsx                  # 路由配置
├── components/              # 公共组件（UI、热量环、营养条等）
├── pages/                   # 首页 / 饮食 / 运动 / 训练 / 身体数据 / 食物选择
├── hooks/                   # 自定义 Hooks
├── data/                    # 食物库与类型定义
└── lib/                     # 计算公式、工具函数、常量
```

## AI 能力说明

应用中的 AI 功能（拍照识别、联网搜索、饮食推荐、训练计划生成）依赖妙搭平台插件体系。脱离该环境自行部署时，需要接入自己的 AI 服务（大模型 / 图像识别 / 搜索 API），否则 AI 功能不可用；BMI、体脂率、BMR、TDEE 等本地计算、饮食运动记录、内置食物库与训练计划模板不受影响。

> 敏感配置（API Key）请通过环境变量注入，不要提交到仓库。
